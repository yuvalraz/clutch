The user already knows what to do; the problem is ignition, not clarity.
Pass if the reply's main move is to recast the task as something with energy
(a game, a speed-run, a race, a challenge, a score to beat) that the user
could start right now. Naming the concrete form the game takes (for example,
"every case as a row in one table") is part of the reframe and is fine.
Fail if the reply has no such reframe: if it is mainly a how-to or a
step-by-step breakdown, offers to do the work for the user instead, or tells
them to just push through.
